## 🔹 **Sandboxes**
Explore different APIs with the following sandboxes:

* **WSS**: [GoSandy](https://app.gosandy.io/)
* **Petstore Swagger**: [Swagger Petstore](https://petstore.swagger.io/#/user/createUser)
* **SpaceX**: [SpaceX Data API](https://docs.spacexdata.com/)
* **Alpha Vantage**: [Alpha Vantage API Documentation](https://www.alphavantage.co/documentation/)  
   Alpha Vantage provides real-time and historical financial market data through a powerful and developer-friendly API.  
   **Free Plan**:  
   - Request Limits: 5 requests per minute, 500 requests per day.  
   - Access to most features, including stock price data, currency pairs, cryptocurrencies, and technical indicators.  
   - Availability: Ideal for infrequent use, prototyping, or small projects.
* **Dadata**: [Dadata API Documentation](https://dadata.ru/api/)  
   A service for working with data, providing various APIs for processing, cleaning, and standardizing information, including addresses, companies, full names, phone numbers, emails, and more.  
   **Basic Free Plan**:  
   - Allows 100–500 requests per day.  
   - Suitable for testing and small projects.  
   - Limitations on request frequency (usually 1-2 requests per second).
